# Changelog

This document summarizes major changes between OctoMatrix releases, loosely following the spirit of [Keep a Changelog](https://keepachangelog.com/) while keeping the project's existing "Major Upgrade Summary" style. See each version's GitHub Release for the full line-item detail.

## [v1.0.0-beta.9] - 2026-09-02

A consolidated release compared to beta.8, covering the Telegram connection architecture, the avatar system, Docker/macOS deployment stability, and GHOST/Harness reliability under the hood.

- **Telegram Gateway switches to Long Polling**: ngrok dependency removed; no inbound port or tunnel needed anymore.
- **Avatar system enhancements**: added `candle_lantern` item, merged the `sumikko` series, avatar help text now generated by dynamically scanning `--help`, `avatar_instruction` moved into a localized template.
- **Docker / macOS deployment stability**: fixed token-paste visual feedback, docker-compose `$` escaping, agy auth now runs in a temporary container, `.env` values shell-quoted, agent-window startup staggered by 5 seconds.
- **GHOST / Harness reliability**: fixed an orphaned-file issue in the reset buffer window, unified awake context depth at 20, added a Harness Cooldown mechanism, hardened `auto_permission_responder.py`.

See [Release v1.0.0-beta.9-en](https://github.com/meso4444/OctoMatrix/releases/tag/v1.0.0-beta.9-en).

## [v1.0.0-beta.8] - 2026-08-13

A single but important reliability fix: scrollback hardening in the GHOST/Cyberbrain terminal-capture layer, fixing the root cause of false-positive idle greetings.

- Added `-S -300` to `cyberbrain_pipe_manager.py`'s `tmux capture-pane` call to include the last 300 lines of scrollback, preventing a busy agent from being misjudged as idle due to a terminal-capture blind spot.

See [Release v1.0.0-beta.8-en](https://github.com/meso4444/OctoMatrix/releases/tag/v1.0.0-beta.8-en).

## [v1.0.0-beta.7] - 2026-08-11

Roughly three weeks of accumulated fixes and hardening, covering a three-channel network security review, native macOS support, and robustness improvements to notifications and cross-agent communication.

- **Security hardening**: `router`/`telegram_gateway` now bind `127.0.0.1` by default; added `secret_token` verification for the Telegram webhook; filename sanitization (preserving CJK filenames) added across all three channels' file downloads, closing a path-traversal risk.
- **Native macOS support**: `config_wizard.py` gained a macOS branch, no longer limited to Linux `useradd`.
- **Notification robustness**: Router now returns HTTP 502 on internal failure; `matrix_notifier.py` added JSON body validation and a plain-text fallback.
- **GHOST & cross-agent comms**: snapshot keywords now sort by recency with pagination support; `agent_intercom.py` timeout raised in stages.
- **Telegram message types**: added receive/forward support for voice, video, video notes, and GIFs.

See [Release v1.0.0-beta.7-en](https://github.com/meso4444/OctoMatrix/releases/tag/v1.0.0-beta.7-en).

## [v1.0.0-beta.6] - 2026-07-23

Covers a virtual-environment isolation architecture for agent runtimes, a full migration of the avatar system to animated WebM, a deep rework of the Ghost reset / `/fix` rescue mechanism, and multi-engine and container isolation hardening.

- **Core architecture**: introduced an overlay virtual environment (self-healing `.pth` mechanism), global skill cache architecture v3, PEP 370 user site-packages redirection.
- **Ghost reset & /fix overhaul**: message queues consolidated into an actively-pulled `task_memo.txt`; unified `.rotation_flag`/`.fix_flag` locking, eliminating restart deadlock risk.
- **Avatar Generator v2**: fully upgraded to animated WebM, added an absolute locking mechanism, 5-generation history backups, `/avatar_renew list`/`restore`.
- **Multi-engine CLI support**: added the Antigravity CLI (agy) engine.
- **Container & permission isolation**: refactored Docker `entrypoint.sh`'s chown logic to be non-recursive and narrowly scoped; applied a sticky bit to agent directories.

See [Release v1.0.0-beta.6-en](https://github.com/meso4444/OctoMatrix/releases/tag/v1.0.0-beta.6-en).

## [v1.0.0-beta.5] and earlier - 2026-06-15 and before

v1.0.0-beta.5 is the existing baseline before this CHANGELOG began tracking releases. Changes prior to beta.5 have not been retroactively compiled; see the GitHub Releases page or commit history for that history.
